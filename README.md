# Strata App

Strata App is a clickable prototype for building managers and contractors. A manager posts a job. Licensed contractors nearby make an offer. The manager approves one, the money is held, the contractor does the work and adds photos, and the money is released when the job is finished.

## How to open it

1. Open the file `index.html` in a web browser such as Chrome, Safari or Edge.
2. You do not need to install anything, and nothing is sent to a server.

The layout is built for a phone. Make the window narrow, or use the browser’s device mode, to see that layout. Widen the window to see the desktop layout, with the sections in a column on the left.

A gold bar says the people, buildings and jobs are sample data. Nothing you do is saved. Refresh the page to start again. The only thing this browser remembers is the light or dark choice.

## A short try-out

1. Stay on Manager. Home asks you to set up the profile.
2. Open Profile. Choose a role, a way to pay, and tick the consent. The page then says the profile is complete.
3. Go back to Home, tap New request, and follow the five steps.
4. Switch to Contractor. Open the new job and send an offer.
5. Switch back to Manager, approve the quote, and pay. The payment is only a demonstration.
6. As the contractor, mark that you are on the way, arrive, answer the safety questions, read the safety guide, and start. Add the photos the page asks for, then submit.
7. As the manager, you can accept the work or ask for a fix. After a second fix, the money is released.

The red Emergency button sits at the bottom of every page except the emergency screens.

Payments, the camera, licence checks, the map and the export are demonstrations only.
